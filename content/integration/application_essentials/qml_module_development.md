Development path for building custom Logos Core modules (plugins) that extend core functionality and run within the [[integration/infrastructure_essentials/logos_core|Logos Core]] runtime environment.

The modules may be:

- Frontend: QML UI Plugins
- Backend or "Business": Using any language that can expose a C-API, still using Qt Plugin framework

Building a module, enables the developer to either:

- Have their applications run as a [[mini app]] in the [[logos launcher]]
- Import their modules via [[vendor]] to build dedicated apps
